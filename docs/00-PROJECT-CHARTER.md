# PROJECT CHARTER — v0.1

## 1. الغرض

بناء موقع ويب بسيط وعملي وقابل للتوسع لدعم المفتشين في جمع معطيات التفتيش ميدانيًا بطريقة منظمة، مع تمكين Admin من هندسة البنية والمواصفات والبنود دون الرجوع إلى المبرمج في كل تغيير.

## 2. المستخدمون

### Admin
- إدارة حسابات المفتشين.
- إدارة المؤسسات.
- هندسة الشجرة المرجعية.
- إنشاء/تعديل المواصفات.
- إنشاء/تعديل بنود التفتيش.
- ترتيب ونقل وتعطيل المحتوى المرجعي.
- مراجعة اقتراحات المفتشين.
- إنشاء Draft ونشر Version جديدة.

### Inspector
- تسجيل الدخول.
- إنشاء زيارة أو استكمال مسودة.
- اختيار أو اقتراح مؤسسة.
- التنقل داخل البنية المنشورة.
- تعبئة المواصفات.
- تقييم البنود بالحالات القياسية.
- كتابة المعاينات والتوصيات.
- إضافة فرع/مواصفة/بند عند الحاجة داخل الزيارة.
- حفظ العمل تلقائيًا.
- تصدير بيانات الزيارة.

## 3. القيمة التشغيلية الأولى

أقصر طريق إلى قيمة حقيقية هو:

**تسجيل دخول → مؤسسة → زيارة → بنية/مجالات → مواصفات وبنود → حفظ → استكمال → تصدير JSON.**

أي Feature لا يخدم هذا المسار مباشرة يؤجل حتى يثبت الاستخدام الحقيقي ضرورته.

## 6. معيار النجاح

يعد V1 ناجحًا عندما يستطيع مفتش تنفيذ زيارة فعلية من الهاتف، إضافة ما لم يكن متوقعًا، إغلاق المتصفح ثم استكمال العمل من حسابه، وتصدير ملف منظم صالح لتحويله إلى تقرير؛ دون حاجة إلى تدخل تقني أثناء الزيارة.

## 7. المبدأ الحاكم للجودة

**جودة المنتج النهائي هي المرجع الأعلى لاتخاذ القرارات.**

المقصود بالجودة هنا ليس المظهر فقط، بل صحة النموذج المفاهيمي، ملاءمة سير العمل للممارسة المهنية، سلامة البيانات والتاريخ، الأمن، الاعتمادية، سهولة الاستخدام، قابلية الوصول، الأداء، قابلية الصيانة، وقابلية التطور.

تُعامل القيود السابقة — مثل Backward Compatibility، العقود والاختبارات القديمة، صيغة Export سابقة، تقليل حجم التغيير، تجنب Migration، أو الحفاظ على تنفيذ قائم — كعوامل هندسية تخدم الجودة ولا تعلو عليها.

إذا كان الحفاظ على قرار أو تنفيذ سابق يخفض جودة المنتج النهائي، يُعاد تصميمه بصورة صحيحة، ثم تُدار آثار الانتقال بوضوح: Migration عند الحاجة، حماية الحقيقة التاريخية، تحديث الاختبارات والعقود، وإتاحة مسار Rollback أو Recovery معقول حيث يلزم.

وعليه: **لا نحافظ على شيء لمجرد أنه موجود أو سبق اختباره؛ نحافظ عليه لأنه ما زال يخدم المنتج الصحيح.**
