# PILOT ACCEPTANCE — V1

هذه القائمة هي البوابة البشرية الأخيرة بعد نجاح CI. لا يُعطى الحكم **PILOT-READY** قبل تنفيذها فعليًا في المتصفح وعلى شاشة هاتف أو عرض يقارب 360px.

## A. التحضير

- [ ] تشغيل نسخة جديدة من الفرع/الـPR المطلوب اختباره.
- [ ] `python manage.py migrate` ينجح.
- [ ] إنشاء Admin محلي.
- [ ] تشغيل `seed_demo` ببيانات خيالية فقط.
- [ ] تسجيل الدخول بحساب Admin.
- [ ] تسجيل الدخول بحساب المفتش التجريبي.

## B. Desktop — Inspector

- [ ] صفحة الدخول عربية RTL وواضحة.
- [ ] Dashboard تعرض زيارة المفتش.
- [ ] فتح الزيارة يعرض الشجرة والتقدم.
- [ ] التنقل إلى فرع متداخل يعمل.
- [ ] تعبئة نص قصير وطويل وعدد وتاريخ ونعم/لا واختيار واحد ومتعدد.
- [ ] حفظ المجال ثم إعادة تحميل الصفحة؛ القيم تبقى.
- [ ] تجربة الحالات الخمس للبند:
  - غير مفحوص
  - غير معني
  - مطابق
  - ملاحظة
  - غير مطابق
- [ ] كتابة معاينة بند وحفظها.
- [ ] كتابة معاينات إضافية وتوصيات للمجال وحفظها.
- [ ] كتابة معاينات وتوصيات عامة للزيارة.
- [ ] إضافة فرع محلي، مواصفة محلية، وبند محلي؛ تظهر فورًا في الزيارة.
- [ ] الإضافات المحلية مميزة بصريًا ولا تغير الـMaster مباشرة.

## C. Admin / Governance

- [ ] Admin يرى هندسة المرجع ولا يراها المفتش.
- [ ] Admin يرى Proposal Inbox.
- [ ] الاقتراحات المحلية تظهر مرة واحدة.
- [ ] تجربة تعديل Proposal قبل الاعتماد.
- [ ] اعتماد Proposal يضيفه إلى Draft Master فقط.
- [ ] رفض Proposal لا يحذف الإضافة من الزيارة الأصلية.
- [ ] تجربة اقتراح مؤسسة: اعتماد / رفض / دمج حسب السيناريو التجريبي.
- [ ] نشر Draft يتطلب تأكيدًا صريحًا.
- [ ] الإصدار المنشور السابق يصبح Archived.
- [ ] Builder لا يحرر الإصدار المنشور بعد النشر.
- [ ] زيارة قديمة تحتفظ بعناوينها وقيمها بعد نشر إصدار جديد.

## D. Export JSON

- [ ] زر «تحميل JSON» يعمل.
- [ ] الملف يفتح UTF-8 والعربية سليمة.
- [ ] يحتوي `schema = inspection-export-v1`.
- [ ] المؤسسة والتاريخ والحالة وإصدار المرجع صحيحة.
- [ ] الشجرة Recursive وبترتيب متوقع.
- [ ] المواصفات والقيم موجودة.
- [ ] البنود والحالات والمعاينات موجودة.
- [ ] المعاينات والتوصيات على مستوى المجال والزيارة موجودة.
- [ ] العناصر المحلية تحمل `local_addition=true`.
- [ ] يوجد Proposal trace للإضافات المحلية عندما يتوفر.
- [ ] لا توجد كلمات مرور، Tokens، أسرار اتصال، أو مفاتيح API.

## E. Mobile / ~360px

- [ ] لا يوجد horizontal scroll غير مقصود.
- [ ] القائمة العلوية قابلة للاستخدام.
- [ ] الأزرار والروابط قابلة للمس بالإبهام.
- [ ] حقول النص والاختيار لا تخرج عن الشاشة.
- [ ] بطاقات البنود وحالاتها مقروءة.
- [ ] زر الحفظ لا يحجب المحتوى.
- [ ] الشجرة المتداخلة لا تتسع أفقيًا بلا حد.
- [ ] الانتقال بين المجالات لا يحتاج zoom يدويًا.

## F. Keyboard / Basic Accessibility

- [ ] يمكن الوصول إلى الروابط والأزرار وحقول الإدخال بواسطة Tab.
- [ ] Focus مرئي بوضوح.
- [ ] Labels مرتبطة بالحقول بصورة مفهومة.
- [ ] الحالة لا تعتمد على اللون وحده.
- [ ] رسائل الحفظ والخطأ مفهومة نصيًا.

## G. Completion / History

- [ ] إنهاء الزيارة يتطلب تأكيدًا.
- [ ] بعد الإنهاء تصبح الزيارة Read-only.
- [ ] محاولة POST للتعديل بعد الإنهاء مرفوضة.
- [ ] JSON للزيارة المكتملة لا يفقد البيانات.
- [ ] تغيير Master لاحقًا لا يغير Export الزيارة القديمة.

## H. Security checklist قبل نشر حقيقي

- [ ] `DEBUG=0`.
- [ ] `DJANGO_SECRET_KEY` قوي وخارج GitHub.
- [ ] `DJANGO_ALLOWED_HOSTS` يقتصر على النطاقات الفعلية.
- [ ] HTTPS فعال.
- [ ] Secure session/CSRF cookies مفعلة.
- [ ] PostgreSQL بدل SQLite للاستخدام متعدد المستخدمين.
- [ ] حسابات Admin محدودة ومراجعة.
- [ ] كلمات مرور قوية وسياسة تغييرها معروفة.
- [ ] لا Demo data في Production.
- [ ] لا أسرار أو ملفات `.env` مرفوعة للمستودع.
- [ ] نسخة احتياطية فعلية أنشئت.
- [ ] استرجاع نسخة احتياطية اختُبر، لا مجرد وجود ملف Backup.

## Verdict

- **TECHNICAL-PASS**: CI والاختبارات الآلية ناجحة.
- **RETEST**: خلل في تجربة المتصفح/الهاتف أو تصدير البيانات.
- **PILOT-READY**: Technical PASS + جميع اختبارات القبول الحرجة أعلاه ناجحة.
