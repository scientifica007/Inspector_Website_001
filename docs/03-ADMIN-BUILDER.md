# ADMIN BUILDER — v0.1

## 1. المبدأ

Admin يبني "مرجع التفتيش" بصريًا. لا يحتاج إلى كود أو SQL.

## 2. الشاشة الأساسية

### يسار: Tree
- عرض الشجرة؛
- فتح/طي؛
- اختيار Node؛
- بحث؛
- ترتيب.

### يمين: Node Editor
- العنوان؛
- الوصف؛
- قابل للتفتيش؟؛
- المواصفات؛
- بنود التفتيش؛
- الفروع؛
- الحالة.

## 3. العمليات

لكل Node:
- + إضافة فرع
- + إضافة مواصفة
- + إضافة بند
- تعديل
- إعادة ترتيب
- نقل إلى...
- تعطيل

لا حذف Hard Delete للمحتوى المستخدم تاريخيًا.

## 4. المواصفات

Admin يحدد:
- العنوان؛
- النوع؛
- إلزامي/اختياري؛
- الخيارات عند الحاجة؛
- ترتيب؛
- شرح اختياري.

## 5. بنود التفتيش

Admin يحدد:
- العنوان؛
- guidance اختياري؛
- الترتيب؛
- active.

الحالات القياسية ليست قابلة للتحرير في V1.

## 6. Draft / Preview / Publish

Admin يعمل دائمًا على Draft.

الإجراءات:
- Save Draft
- Preview as Inspector
- Publish

Publish:
- ينشئ Master Version جديدة؛
- لا يعدل Version قديمة؛
- لا يغير زيارة قائمة.

## 7. Proposal Inbox

التصنيفات:
- مؤسسات؛
- Nodes؛
- Specifications؛
- Items.

خيارات القرار:
- Approve
- Edit then Approve
- Merge
- Reject

Approve يضيف إلى Draft المستقبلية، لا إلى Version منشورة بأثر رجعي.

## 8. منع التكرار

قبل اعتماد أو إضافة محتوى مرجعي:
- بحث نصي عن عناصر مشابهة؛
- إظهار الأقرب؛
- Admin يقرر الدمج أو الإضافة.

لا AI مطلوب في V1 لهذا الغرض.

## 9. Governance بسيطة

V1 لا يحتاج Workflow موافقات متعدد المستويات.
Admin واحد مخول يكفي كبداية.
